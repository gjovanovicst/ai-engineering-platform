# Design System — AI Implementation Spec

> Ovaj dokument je izvor istine za sve UI odluke. AI agent koji implementira
> bilo koji ekran MORA koristiti vrednosti i ugovore definisane ovde.
> Ako vrednost nije ovde definisana, AI NE SME izmisliti novu — mora
> postaviti pitanje ili koristiti najbliži definisani token.

## 0. Pravila za AI agenta (MUST / NEVER)

MUST:
- Koristiti samo tokene iz §1 (nijedna hardkodovana boja/font/spacing).
- Svaku komponentu implementirati po ugovoru iz §3.
- Za svaki ekran poštovati composition iz §5.
- Podržati light + dark kroz CSS varijable (§1.3).
- Testirati na 3 breakpointa: mobile (375px), tablet (768px), desktop (1280px+).
- Svaka akcija mora imati loading, empty i error stanje.

NEVER:
- Uvoditi novu boju, spacing ili font bez ažuriranja §1.
- Koristiti inline style za boje/spacing — samo Tailwind klase ili token.
- Kreirati `<div>` bez semantičkog razloga (koristiti `<section>`, `<article>`, `<nav>`).
- Prikazivati procenjene podatke kao izmerene (spec §3.10) — svaka metrika
  mora imati `source: 'measured' | 'estimated' | 'n/a'` polje.
- Koristiti animacije duže od 300ms (osim skeleton loading).
- Dodavati drop-shadow na kartice (enterprise look — senke su zabranjene,
  osim za elevated: modal, dropdown, tooltip).

## 4. State machine (svaka lista/tabela/kartica MORA imati ova stanja)

\`\`\`

empty	EmptyState sa CTA dugmetom

6. Responsive rules
Breakpoint	Promena
< 640px	Sidebar se skriva u hamburger; ContentGrid → 1 kolona; KPI grid → 1 kolona; DataTable → card list
640-1024px	Sidebar collapsed (64px, samo ikone); ContentGrid → 1 kolona; KPI grid → 2 kolone

>= 1440px	Content max-width: 1440px, centrirano

7. Accessibility (obavezno)

Svaki interaktivni element ima aria-label ili vidljiv tekst.

Focus ring: focus-visible:ring-2 focus-visible:ring-brand focus-visible:ring-offset-2.

Kontrast: minimalno WCAG AA (4.5:1 za tekst, 3:1 za UI).

Modali: role="dialog" aria-modal="true", fokus trap.

Status badge: ne samo boja — uvek ima i tekst ili ikonu (color-blind safe).

Keyboard navigacija: Tab redosled prati vizuelni red, Escape zatvara overlaye.

8. Anti-patterns (AI NE SME)
❌ Ne	✅ Da
<div style={{color: '#6366F1'}}>	className="text-brand"
Procenjena vrednost bez oznake	<KpiCard source="estimated" ...>
Prazan <div> umesto liste	<EmptyState />
Hardkodovan spacing margin-top: 24px	className="mt-6"

Animacija > 300ms	duration-150

10. Verifikacija (AI mora pokrenuti pre "done")

```bash

1. Nema hardkodovanih boja u komponentama

2. Nema inline color style

grep -rnE 'style={{[^}]*color' src/ || echo "OK"

3. Svaki ekran ima test fajl

find src/app -name 'page.tsx' | while read f; do
test -f "${f%.tsx}.test.tsx" || echo "MISSING TEST: $f"
done

4. TypeScript prolazi

tsc --noEmit

5. E2E ključnih tokova

pnpm test:e2e
```
