# v0.1.0 — 2026-11-17

**AI Engineering Platform — first public developer preview.**

A self-hosted platform where AI agents execute the software lifecycle — idea,
blueprint, backlog, planning, implementation, tests, review, merge, deploy —
with a human at every gate and a full audit trail. The backend is Go, the web
is Next.js, the database is PostgreSQL.

## Highlights

- **ASDLC with gates**: plan approval, test gate, secret scan, agent review,
  human PR approval and merge, all recorded as run events.
- **Agent runtime**: a tool loop over a network-isolated sandbox, per-repo git
  credentials, Go module fetch for offline sandboxes, and a step budget that
  always leaves room for the final answer.
- **Review and failure UX**: the run page shows the failure detail, a Retry
  action, and links a failing CI check to its CI job.
- **Evidence, not claims**: every run records a diff, test report, acceptance
  proof, review findings and an event stream; the pilot app was built through
  ten such runs.
- **Deployable**: docker compose for local and K8s manifests for a cluster,
  with cosign-signed images, provenance and SBOMs.

## Images

```
ghcr.io/gjovanovicst/ai-engineering-platform/api:v0.1.0
ghcr.io/gjovanovicst/ai-engineering-platform/web:v0.1.0
ghcr.io/gjovanovicst/ai-engineering-platform/sandbox:v0.1.0
```

The sandbox image is required for agent runs:

```sh
AIP_SANDBOX_IMAGE=ghcr.io/gjovanovicst/ai-engineering-platform/sandbox:v0.1.0
```

The web image inlines `NEXT_PUBLIC_API_URL` at **build** time. The release
workflow reads the repository variable `AIP_WEB_API_URL`; set it to the URL your
browser uses for the API before tagging a release.

## Quickstart

See [docs/quickstart.md](../quickstart.md): docker compose for the
infrastructure, migrations, the sandbox image, then register in the web UI.

## Known limits

- **Developer preview**: self-hosted only; there is no hosted SaaS. Multi-tenant
  isolation, abuse controls and support are out of scope for v0.1.
- **An LLM provider key is required** for agent runs (`AIP_PROVIDER_*`).
- **The worker needs the Docker socket** to run the sandbox image.
- **No demo seed is shipped**: register through the web UI, then create your
  organization, project and repository. Fine-grained GitHub PAT scopes:
  Contents RW, Pull requests RW, Workflows RW (plus Actions: Read for checks).
- **The platform never merges on its own**: a human approves the PR; branch
  protection should require the same checks.
