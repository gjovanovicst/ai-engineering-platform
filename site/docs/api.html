Download OpenAPIAPI basicsEvent catalog

Authentication

All endpoints except /auth/* and /healthz require a bearer token. Obtain one with the login endpoint, then send it in the Authorization header.

TOKEN=$(curl -s -X POST http://localhost:18080/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"you@company.com","password":"..."}' | jq -r .access_token)

curl -H "Authorization: Bearer $TOKEN" \
  http://localhost:18080/api/v1/orgs/$ORG/projects
SchemeTypeDescription
bearerAuthhttpSend Authorization: Bearer &lt;access token&gt;.

Servers: /api/v1

Every path except /auth/* and /healthz is organization-scoped. Access tokens are short-lived; refresh tokens rotate.

Base URL: http://localhost:18080/api/v1 locally, or your deployment URL plus /api/v1.

Conventions: cursor pagination with limit/cursor; Idempotency-Key on mutations; errors returned as {"error":{"code","message","request_id"}}; 429 includes Retry-After. See API basics.
