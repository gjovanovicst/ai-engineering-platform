Release notes

The changes that reach you, newest first. The full history is in CHANGELOG.md.

v0.2.0

  • The AI assistant: a side panel that reads the workspace and drafts tasks, projects and retries behind a confirmation.
  • The slash commands: /create-task, /create-project, /triage, /standup, /help and more.
  • The chat history with delete and clear.
  • The setup wizard (/setup): the provider, the repository, the test command and the sandbox.
  • The run page polish: a sticky action, a timeline, the blockers first.

v0.1.1

  • The task composer and the scope fields (in / out of scope).
  • The forms foundation and the consistent forms across the app.
  • The guidance layer (the help tips and the empty states).
  • The command palette (⌘K).
  • Retry development, Fix review findings and Fix CI from the run page.
  • The per-project test command and the task composer.
  • The clean audit.
  • The template gallery and the reference implementations.

v0.1.0

The first release: the projects, the tasks, the runs, the approvals, the pull requests and the quality gates.
